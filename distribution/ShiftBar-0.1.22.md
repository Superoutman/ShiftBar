胶囊右键菜单新增「复制诊断信息」。遇到调节条不出现、「布局检查未通过」或调整后恢复旧范围时，可以复制报告并自行粘贴到 GitHub Issue，帮助定位失败阶段。

报告记录失败时的检查结果，并在复制时连续两次读取各显示器的菜单栏布局。报告中的第三方应用图标使用匿名编号；不包含第三方应用名称、文件路径或完整设置。复制不会自动上传，也不会修改已保存的隐藏范围。

**仍存在的已知问题**

隐藏范围包含电池、Wi‑Fi 等系统图标时，展开仍可能出现短暂闪动或横移。本次更新增加诊断能力，未改变此行为。若菜单栏存在原生溢出箭头（`«`），可尝试通过箭头查看相关系统图标，以缓解主栏横移；效果取决于各屏布局。
